# 异动监测信息集：看什么、怎么判断、何时提醒

版本：V2 / 2026-10-12。按仓库 e64e1611 的代码和所附Excel核对。这里区分产品目标规则与当前原型实现；所有候选阈值仍未校准。

## 先把四件事分开

- **信号**：观察到某个变化，例如成交量达到平时2倍。它不自动等于风险，也不自动解释原因。
- **事件**：把同一件事涉及的信号和证据合在一起，例如某公司放量下跌并发布业绩预警。
- **风险程度**：轻微(S1)、重要(S2)、严重(S3)。根据已确认的事实判断；不知道的单列，不能填成正常。
- **提醒优先级**：这件事值得多快通知这个用户。持仓、偏好和开关可以改变顺序或是否推送，不能改写事实程度。

## 提醒规则怎么读

稳健型更早提醒；平衡型用默认候选线；进取型容忍更多普通波动。三档是用户选择的通知模板，不是已经完成的风险适当性评估。正式重大风险不能因为用户偏进取而改成轻微；通知仍尊重用户明确开关。

数值越线后，先核对数据有效、交易时段、公司行为和用户范围。未达到本项门槛只表示本项不触发，不能说整只股票没有风险。日终量比和盘中同时间量比不得混用；换手率分母不能在总股本、流通股和自由流通股之间偷换。

## 每项用同一套问题解释

### 大环境

#### M01 借钱的成本变了

看央行是否加息、降息或改变资金投放，再看这家公司是否会受到融资成本变化的影响。

- 看什么数据：政策利率、降准、公开市场操作、资产购买/缩表
- 怎么计算：正式决定对比前次；有存档预期时再比较预期
- 稳健型：正式参数变化且业务相关即进入摘要；超预期≥0.25个百分点时提醒
- 平衡型：超预期≥0.25个百分点且有融资成本或业务影响时提醒
- 进取型：普通参数变化入摘要；超预期≥0.5个百分点且有受影响业务或债务时提醒
- 程度与影响：轻微(S1)参数变化；重要(S2)超预期≥0.25个百分点且相关；非例行措施按重要影响定重要(S2)/严重(S3)；融资成本、估值折现、净息差；方向按净借款/存款及资产负债判断
- 合成例子：预期加息0.25个百分点，决定加息0.5个百分点；差0.25个百分点，浮息债务占比高→重要(S2)，平衡型提醒。缺预期快照不能称超预期。
- 不要误读：有正式政策变化也不等于股价一定同方向变化。
- 当前实现：未接入；需要宏观原始数据和适用范围

#### M02 经济数据和预期差很多

看物价、就业和经济增长公布值，与公布前市场预期差多少，判断是否需要重新评估需求或利率。

- 看什么数据：CPI、就业、GDP、PMI；实际值、预期值、修订值
- 怎么计算：公布值减去事先保存的预期，得到超预期差；再按此前24次差值计算异常分数z（计算方法见说明）。历史不足或MAD为0时不自动给等级。
- 稳健型：|z|≥2且业务相关时提前提醒
- 平衡型：|z|≥3且业务相关时提醒
- 进取型：|z|≥4且业务相关时提醒
- 程度与影响：轻微(S1)：2≤|z|<3；重要(S2)：|z|≥3；单一统计惊喜不自动定严重(S3)；可能重估利率、需求或成本；通胀/就业指标的方向分别解释
- 合成例子：CPI实际3.6%、发布前预期3.2%；历史误差中位0个百分点、MAD=0.08个百分点，z=3.37→重要(S2)；若输入口径不同先停算。
- 不要误读：没有事先保存的预期，就不能说超预期；异常分数衡量罕见程度，不是跌幅预测。
- 当前实现：未接入；需要宏观原始数据和适用范围

#### M03 政策改变了公司的生意

看关税、出口限制、补贴或经营许可的新规定，是否真正改变了公司的收入、成本或经营条件。

- 看什么数据：关税、出口许可、产业准入、补贴、限价、数据监管等
- 怎么计算：政策适用范围/义务/税率/时间相对旧版有无实质变化
- 稳健型：相关草案入摘要；正式新政通过四门槛即提醒
- 平衡型：正式原文＋实质变化＋真实业务命中＋重要影响时提醒
- 进取型：重要(S2)一般影响入摘要；主营/许可/关键供给受限或严重(S3)即时提醒
- 程度与影响：轻微(S1)候选关联；重要(S2)重要业务受影响；严重(S3)主营许可撤销/禁止核心经营；草案不得冒充已生效；收入、成本、融资或经营资格；影响大小未知时保留未知
- 合成例子：正式出口限制30天后生效；X产品收入占比40%且目的地匹配→重要(S2)，平衡型提前提醒；40%不是预计损失。
- 不要误读：先找正式文件、看新旧差别、核实业务适用范围，再谈影响；行业标签相同不等于适用。
- 当前实现：人工整理事件；不是自动采集、核验政策。当前事件未按三档语义做自动筛选。

#### M04 汇率变化影响收入或还债

看公司收钱、付钱、借钱所用的货币变了多少，以及有没有措施抵消这种影响。

- 看什么数据：USD/CNY、USD/CNH及公司收入/成本/债务相关币种
- 怎么计算：同一货币对的1日变动；同时核对净受影响金额（考虑收入、成本、债务与对冲）和对冲
- 稳健型：1日汇率变动绝对值≥1%且存在净受影响金额时提醒
- 平衡型：绝对值≥2%且存在净受影响金额时提醒
- 进取型：绝对值≥3%且存在净受影响金额时提醒
- 程度与影响：轻微(S1)：1%至不足2%；重要(S2)：≥2%且有受影响业务或债务；单一汇率变动不自动定严重(S3)；收入折算、进口成本、外币偿债；需考虑自然及金融对冲
- 合成例子：本币对债务币种贬值2.2%，外币债务未充分对冲→重要(S2)敏感性提醒；缺对冲信息不推算确定损失。
- 不要误读：同样的汇率变化，出口商和进口商的影响可能相反；缺少对冲信息不估算确定损失。
- 当前实现：未接入；需要宏观原始数据和适用范围

#### M05 原料、能源或运费突然变贵

看公司主要投入或出售的商品价格是否明显变化，判断成本或售价可能受什么影响。

- 看什么数据：原油、金属、能源价格、运价等关键投入/产出价格
- 怎么计算：同基准、同期限价格的1日变化
- 稳健型：投入/产出价格1日绝对变动≥3%且业务相关时提醒
- 平衡型：绝对变动≥5%且业务相关时提醒
- 进取型：绝对变动≥8%且业务相关时提醒
- 程度与影响：轻微(S1)：3%至不足5%；重要(S2)：≥5%且相关；供给中断另看C08；原材料成本、售价、毛利或订单交付；上游与下游方向可能相反
- 合成例子：原油1日+6%，公司主要成本为燃料且未充分对冲→重要(S2)成本压力；不能把上游油企也一律判利空。
- 不要误读：原油上涨可能利好产油企业、压低航空公司利润，不能统一写成利空。
- 当前实现：未接入；需要宏观原始数据和适用范围

#### M06 整个市场一起承压

看市场波动、融资和信用压力是否同时明显上升，识别普遍性的风险环境。

- 看什么数据：市场回撤、波动率、信用利差、融资压力
- 怎么计算：各指标风险方向相对过去252交易日分位
- 稳健型：一项风险指标>历史95分位且存在市场暴露时提醒
- 平衡型：至少两项同向风险指标>各自95分位且有暴露时提醒
- 进取型：至少两项>99分位且有暴露时提醒；严重(S3)不延后
- 程度与影响：轻微(S1)一项>95分位；重要(S2)两项>95分位；严重(S3)须另有正式系统性紧急事件；普遍估值重定价、融资收紧；不归因于个股经营恶化
- 合成例子：波动率97分位、信用利差96分位且持有该市场股票→重要(S2)；只出现波动率升高→轻微(S1)。
- 不要误读：这说明市场环境恶化，不证明某家公司经营出了问题。
- 当前实现：未接入；需要宏观原始数据和适用范围

### 行业与上下游

#### I01 整个行业比大盘弱

比较行业整体与大盘的表现，判断压力是不是集中在某个行业。

- 看什么数据：行业指数收益、市场收益、行业成员变化
- 怎么计算：行业1日收益−市场1日收益
- 稳健型：行业1日落后市场≥1个百分点时提醒
- 平衡型：单日落后≥4个百分点或连续2日各≥2个百分点时提醒
- 进取型：连续2日各落后≥3个百分点时提醒；严重(S3)仍按通用规则
- 程度与影响：轻微(S1)单日落后≥2个百分点；重要(S2)单日≥4个百分点或连续2日各≥2个百分点；不自动定严重(S3)；板块资金偏好或共同经营预期走弱；只提示相对弱势
- 合成例子：行业-5%、市场-1%→相对-4个百分点，重要(S2)；市场与行业均-5%不构成该信号。
- 不要误读：先选正确行业和指数；行业一起跌不能直接归因到某家公司。
- 当前实现：未接入；需要行业或真实业务关系数据

#### I02 行业销量、订单变差

跟踪行业销量、订单、库存和开工情况，判断经营环境是否持续转弱。

- 看什么数据：订单、产销量、库存、价格、产能利用率
- 怎么计算：同统计口径、同季节性的同比变化
- 稳健型：关键经营指标同比恶化≥10%且业务相关时提醒
- 平衡型：连续2次恶化≥10%或单次≥20%时提醒
- 进取型：连续2次恶化≥20%时提醒；重大停供走事件路径
- 程度与影响：轻微(S1)单次恶化≥10%；重要(S2)连续2次≥10%或单次≥20%；先定义好坏方向；销量、订单、产能利用、库存压力；影响下一期经营
- 合成例子：公司所在行业订单连续两月同比-12%、-15%→重要(S2)；季节性库存备货增加不能直接判恶化。
- 不要误读：库存增加可能是备货，也可能是卖不动，需要结合销量和季节判断。
- 当前实现：未接入；需要行业或真实业务关系数据

#### I03 客户或供应商可能传来风险

看重要客户、供应商发生了什么，再确认合作关系、依赖程度和替代方案。

- 看什么数据：关键客户/供应商身份、采购/收入占比、替代性
- 怎么计算：公司披露的真实关系与新事件
- 稳健型：真实重要客户/供应商出现已证实事件即提醒
- 平衡型：关键伙伴确认停供/违约/重大砍单且影响主营时提醒
- 进取型：普通伙伴事件入摘要；关键不可替代伙伴中断即提醒
- 程度与影响：轻微(S1)伙伴候选风险；重要(S2)确认重要传导；严重(S3)已造成核心业务停摆；收入损失、原料短缺、履约及回款风险
- 合成例子：供应商占采购18%，正式确认停供且无短期替代→重要(S2)；无法证明合作关系则待核实。
- 不要误读：客户股价下跌只是核查线索，不等于已经砍单；演示里的跨市场映射不等于核实了供应链。
- 当前实现：演示线索：美国龙头日涨跌达到3%/5%/8%触发人工映射；关系和占比未核实，不代表客户已砍单。

#### I04 同行事件可能波及这家公司

看同行的监管、产品或经营事件，是否通过相同产品、技术、客户或规则影响自选公司。

- 看什么数据：同业召回、监管限制、财报及共同业务机制
- 怎么计算：是否共享同一产品、技术、客户或监管范围
- 稳健型：同业事件与公司存在可证实共同机制时提前提醒
- 平衡型：官方适用范围覆盖公司或公司确认受影响时提醒
- 进取型：普通同业事件入摘要；直接命中主营或严重(S3)才即时提醒
- 程度与影响：轻微(S1)共同机制；重要(S2)直接适用/确认受影响；严重(S3)按经营停摆等事实判定；行业连带监管、产品缺陷或订单预期变化
- 合成例子：同业产品被禁，监管文件明确覆盖相同技术，公司确有该产品→重要(S2)；单纯同行标签不够。
- 不要误读：仅仅属于同一行业不够，需要指出共同影响路径。
- 当前实现：未接入；需要行业或真实业务关系数据

### 股价与成交

#### P01 几分钟内急涨急跌

看同一交易时段内，股价在5分钟里变了多少，成交是否也明显放大。

- 看什么数据：5分钟收益、日收益、报价状态
- 怎么计算：5分钟收益=当前可比价/5分钟前可比价−1；日收益=当前可比价/上一完整交易日可比收盘价−1；均使用同一调整方式
- 稳健型：5分钟收益≤-1.5%且成交量倍数≥1.5时提前提醒
- 平衡型：5分钟收益≤-3%且成交量倍数≥2时提醒
- 进取型：5分钟收益≤-4%且成交量倍数≥2.5时提醒；严重(S3)不延后
- 程度与影响：轻微(S1)绝对变动≥1.5%；重要(S2)下跌≥3%且RVOL≥2；严重(S3)下跌≥5%且RVOL≥3并连续2次分钟快照满足；短时抛售压力、波动放大；不能仅凭价格识别卖方或原因
- 合成例子：5分钟-3.2%，同时间成交量倍数=2.2→重要(S2)，稳健/平衡提醒；进取入摘要。若+3.2%只能标上涨异动。
- 不要误读：只能说明短时变动明显，不能据此知道是谁在交易或为什么交易。
- 当前实现：未接入；需要该项所需行情、盘口或交易所数据

#### P02 成交量比平时大多少

把本次成交量与过去20个可比交易日的中间水平比较。2倍表示成交股数是基准的2倍。

- 看什么数据：累计量、过去20日同分钟累计量、成交额
- 怎么计算：同时间成交量倍数=今日截至t成交量/过去20个可比日同t成交量中位数
- 稳健型：成交量倍数≥1.5进摘要；有负面价格/事件确认才提醒
- 平衡型：成交量倍数≥2进摘要；同时满足P01/P03或正式负面事件才提醒
- 进取型：成交量倍数≥3进摘要；符合本偏好负面组合时提醒
- 程度与影响：单项轻微(S1)活跃度；量比≥3是强放量，不自动升负面重要(S2)；组合等级取事件等级；关注度和交易活跃增加，方向取决于价差、价格与公告
- 合成例子：同时间累计220万股/历史中位100万=2.2；股价平稳→轻微(S1)摘要；量比1.01仅表示略高基线。
- 不要误读：成交股数不是人数；大于1只说明高于基准。日终量比和盘中同时间量比分开使用。
- 当前实现：已实现日终版：当天总成交量/此前20日总量中位数；不是盘中同时间版。命中P10时P02不重复列出。

#### P03 这只股票比行业跌得多

比较股票和行业同一时间段的涨跌，筛出相对更弱的股票。

- 看什么数据：个股与行业同窗口收益
- 怎么计算：个股1日收益−行业1日收益
- 稳健型：日收益落后行业≥2个百分点且成交量倍数≥1.5时提醒
- 平衡型：落后≥4个百分点且成交量倍数≥2时提醒
- 进取型：落后≥6个百分点且成交量倍数≥2.5时提醒
- 程度与影响：轻微(S1)落后≥2个百分点；重要(S2)落后≥4个百分点且RVOL≥2；单项不定严重(S3)；个股相对承压；可提示核查特有事件，不虚构原因
- 合成例子：股票-6%、行业-1%，相对-5个百分点，RVOL=2.2→重要(S2)；两者同跌不算特有弱势。
- 不要误读：相对弱势是核查线索，不能直接断定公司出了事。
- 当前实现：未接入；需要该项所需行情、盘口或交易所数据

#### P04 想成交要付出更大代价

看买卖报价差是否变大、可成交挂单是否变少，识别流动性变差。

- 看什么数据：买卖价差、盘口深度、成交额、报价心跳
- 怎么计算：相对价差=(卖一−买一)/中间价；中间价=(卖一+买一)/2；深度为中间价±0.5%内双边挂单金额；各自对比前20可比日同时间中位数
- 稳健型：价差≥历史2倍且≥0.2%，持续1分钟时提醒
- 平衡型：上述价差＋近端深度≤历史50%，同时持续5分钟时提醒
- 进取型：价差≥历史3倍且≥0.3%、深度≤历史30%，持续5分钟时提醒
- 程度与影响：轻微(S1)价差异常；重要(S2)平衡组合；严重(S3)须确认无法正常交易，不能仅凭单次空盘口；交易成本和滑点上升、卖出难度增大
- 合成例子：价差由0.10%至0.25%(2.5倍)，±0.5%盘口深度由100万至40万，持续5分钟→重要(S2)。
- 不要误读：挂单可能撤回；一张盘口截图不足以证明持续卖不出去。
- 当前实现：未接入；需要该项所需行情、盘口或交易所数据

#### P05 从近期高点跌下来多少

比较现价与最近20个交易日的最高可比收盘价，并另看每天波动是否变大。

- 看什么数据：20日回撤、20日实现波动率
- 怎么计算：回撤=当前可比价/过去20完整交易日最高可比收盘价−1（截断上限为0）；20日波动=20个日对数收益的样本标准差×√252；波动基准为此前60个已知20日波动值的中位数
- 稳健型：20日回撤≤-8%时提醒；波动≥基准1.5倍进摘要
- 平衡型：回撤≤-12%提醒；或波动≥2倍且有负面佐证时提醒
- 进取型：回撤≤-18%提醒；或波动≥3倍且有负面佐证时提醒
- 程度与影响：轻微(S1)回撤≥8%或波动1.5倍；重要(S2)回撤≥12%或负面波动组合；严重(S3)仍需重大额外事实；已发生回撤、未来交易区间可能扩大；不保证继续下跌
- 合成例子：可比价格由20日最高100跌至87→回撤-13%，重要(S2)；波动翻倍但上涨不直接判利空。
- 不要误读：回撤描述已经发生的下跌，不保证以后继续跌。当前程序只实现回撤部分。
- 当前实现：部分实现：20日收盘回撤，且当日收盘不高于窗口最低值时提示；不是独立波动率模型，也不是只在首次创新低提示。

#### P06 跌到了近期平均价下方

比较收盘价和最近20日平均收盘价，观察是否连续跌破，而不是只看盘中一瞬间。

- 看什么数据：MA20、RSI14、MACD及完整K线
- 怎么计算：20日均线=最近20个可比收盘价的平均值（含当日）；跌破幅度=1−当日收盘/均线。收盘确认，边界与连续次数按预先固定规则。
- 稳健型：完整日线首次跌破20日均线超过1%时提醒
- 平衡型：连续2日各低于20日均线≥1%且第二日成交量倍数≥1.5时提醒
- 进取型：连续3日各低于20日均线≥2%且第三日成交量倍数≥2时提醒
- 程度与影响：轻微(S1)首次破位/RSI14<30；重要(S2)平衡组合；单项不定严重(S3)；趋势走弱、技术条件变化；与基本面风险分别记录
- 合成例子：连续2日收盘均低于各日20日均线的1.2%，第二日RVOL1.8→重要(S2)；盘中跌破但收回不算。
- 不要误读：均线不是持仓成本，低于均线不代表多数投资者已经亏损。
- 当前实现：部分实现：MA20跌破；边界用严格小于，文档的至少1%与实现有差异。RSI/MACD未用于触发。

#### P07 交易被限制或暂停

看交易所公布的交易边界和状态，识别临时暂停、触及价格边界等交易限制。

- 看什么数据：有效涨跌边界、VCM/LULD/交易暂停状态
- 怎么计算：当日规则快照与交易所状态通知
- 稳健型：距离有效下限≤参考价1%进入提示；正式机制事件即提醒
- 平衡型：正式交易所机制触发/暂停即时提醒
- 进取型：同平衡；可交易性变化不延后
- 程度与影响：轻微(S1)接近有效边界；重要(S2)确认短暂限制/暂停；严重(S3)按正式长期不可交易事实；交易中断或成交受限；规则含义不能互相替代
- 合成例子：有效规则快照给出下限9.00，参考价10；现价9.08→距离0.8%为轻微(S1)；必须官方确认才称暂停。
- 不要误读：不同市场、板块和证券规则不同；靠近边界不等于已触发暂停。
- 当前实现：未接入；需要该项所需行情、盘口或交易所数据

#### P08 两地上市价格差得反常

统一币种和每股对应份额后，比较同一公司在两个市场的同步价格。

- 看什么数据：A/H/ADR价格、汇率、存托比例、同步状态
- 怎么计算：同币种同单位价差对比过去60个可比日
- 稳健型：同步且|价差z|≥2时提醒
- 平衡型：同步且|价差z|≥3时提醒
- 进取型：同步且|价差z|≥4时提醒
- 程度与影响：轻微(S1)：2≤|z|<3；重要(S2)：≥3；单项不定严重(S3)，也不自动判负面；跨上市地定价偏离、兑换及流动性差异
- 合成例子：汇率/存托比例统一后价差z=3.3，两地均开市且报价差10秒→重要(S2)价差异动；不等于可套利。
- 不要误读：时间错位、兑换限制和交易成本都可能造成价差；不能直接称无风险套利。
- 当前实现：未接入；需要该项所需行情、盘口或交易所数据

#### P09 流通股份交易得异常频繁

成交股数除以有效流通股数得到换手率，再与过去同一时点的换手率比较。

- 看什么数据：同时间累计成交股数、有效流通股本、历史换手率
- 怎么计算：T(t)=累计成交股数/当时有效流通股本；异常倍数=T(t)/过去20个可比日同时间T中位数
- 稳健型：换手异常倍数≥1.5且5分钟收益≤-1.5%时提醒
- 平衡型：换手异常倍数≥2.5且5分钟收益≤-3%时提醒
- 进取型：换手异常倍数≥4且5分钟收益≤-5%时提醒
- 程度与影响：单独高换手轻微(S1)；平衡负面组合重要(S2)；换手≥10%、倍数≥4、5分钟≤-5%并连续2次分钟快照命中为严重(S3)；筹码交换加速、分歧加大；不能仅凭高换手认定主力出货
- 合成例子：累计800万股/有效流通股1亿=8%；同时间历史换手中位3%，倍数2.67；5分钟-3.2%→重要(S2)。
- 不要误读：8%换手不是8%的股东卖出了，也不说明有人出货；先确认流通股本口径。
- 当前实现：未接入：行情无换手字段；当前indicators函数也没有P09触发分支，补数据后仍需补实现。

#### P10 把涨跌和成交量一起看

同时观察价格方向和成交量：价格下跌且放量值得留意；价格上涨且放量属于另一种异动。

- 看什么数据：日涨跌、同时间RVOL20、5分钟价格轨迹
- 怎么计算：日收益=当前可比价/上一完整交易日可比收盘价−1；放量≥1.5、缩量≤0.8；中间区间为无明确量能形态
- 稳健型：日收益≤-2%且成交量倍数≥1.5时提醒
- 平衡型：日收益≤-3%且成交量倍数≥2时提醒
- 进取型：日收益≤-5%且成交量倍数≥3时提醒
- 程度与影响：轻微(S1)放量/缩量形态；重要(S2)平衡放量下跌组合；严重(S3)日跌≥8%且RVOL≥4并连续2次分钟快照命中；放量上涨：活跃向上；放量下跌：抛压；缩量上涨：参与不足；缩量下跌：弱势但抛压不明确
- 合成例子：日收益-4%、RVOL2.4→重要(S2)放量下跌；日收益+4%、RVOL2.4为正向活跃轻微(S1)，不写利空。
- 不要误读：每笔交易都有买卖双方；不能用成交量推算买卖人数，也不能把放量上涨写成利空。
- 当前实现：已实现日线组合；只有日终数据，未做连续两次分钟确认。表中完整目标规则不等于当前全部实现。

#### P11 开盘价跳了一大截

比较今日开盘与昨日可比收盘价，并用平时的价格波动幅度判断这次缺口有多大。

- 看什么数据：正式开盘价、上一日可比收盘价、上一日ATR14
- 怎么计算：缺口=开盘价−昨收；G=|缺口|/昨日ATR14；TR=max(H−L,|H−前收|,|L−前收|)，ATR14使用Wilder平滑
- 稳健型：开盘向下缺口/昨日ATR14≥1且绝对缺口≥1%时提醒
- 平衡型：向下缺口/ATR14≥1.5且缺口≥2%时提醒
- 进取型：向下缺口/ATR14≥2且缺口≥3%时提醒
- 程度与影响：轻微(S1)稳健条件；重要(S2)平衡条件；缺口本身不自动定严重(S3)；隔夜信息重定价、跳空风险；先排除公司行为
- 合成例子：昨可比收盘100、今开96、昨日ATR14=2→缺口-4%、2ATR，重要(S2)；除息造成的缺口先校正。
- 不要误读：缺口可能来自新消息，也可能来自除权；先校正，再判断。
- 当前实现：已实现日线开盘缺口/昨日ATR；上下跳空均识别，自动事件收盘后才可见；不是实时开盘提醒。

#### P12 现价偏离今天的成交均价

用每笔成交的股数加权，计算当天成交均价，再比较现价偏离多少、持续多久。

- 看什么数据：有效逐笔成交价、成交股数、当日交易阶段
- 怎么计算：成交均价=Σ(逐笔成交价×股数)/Σ股数；偏离=当前价/成交均价−1；每日常规时段重置
- 稳健型：价格较当日成交均价≤-1%且成交量倍数≥1.5，持续5分钟时提醒
- 平衡型：偏离≤-2%且成交量倍数≥2，持续5分钟时提醒
- 进取型：偏离≤-3%且成交量倍数≥3，持续5分钟时提醒
- 程度与影响：轻微(S1)负偏离≥1%；重要(S2)平衡组合；单项不定严重(S3)；价格低于当日成交均价，短时卖压；不是所有持有人亏损
- 合成例子：逐笔成交均价50，最新价48.8→-2.4%，RVOL2.2且持续5分钟→重要(S2)；分钟近似成交均价须单独标注。
- 不要误读：成交均价不是所有人的持仓成本；不能据此断定多数人亏损或卖方人数更多。
- 当前实现：未接入；需要该项所需行情、盘口或交易所数据

### 公司经营

#### C01 公司下调赚钱预期

看公司正式财报或经营指引是否明显变差，并把当前与上次的同口径数据比较。

- 看什么数据：营收/利润/EPS、业绩预告、管理层指引
- 怎么计算：同口径指引中值对比前值；季度指标对比同比/存档预期
- 稳健型：同口径指引中值下调≥10%时提醒
- 平衡型：下调≥20%、由盈转亏或正式重大预警时提醒
- 进取型：下调≥30%时提醒；由盈转亏及重大正式预警不延后
- 程度与影响：轻微(S1)下调≥10%；重要(S2)≥20%或由盈转亏；持续经营风险可升严重(S3)；收入/盈利预期下修，可能触发估值调整
- 合成例子：年度利润指引中值100降至75，同比较降25%→重要(S2)，平衡型提醒；不同会计口径先转换。
- 不要误读：公司自己的指引变化和市场预期差是两件事；不同会计口径不能直接比。
- 当前实现：未接入；需要公告和财报

#### C02 利润有没有变成现金

比较账面利润与经营活动收回的现金，再看应收款是否越来越难收。

- 看什么数据：经营现金流、净利润、应收与存货
- 怎么计算：最近12个月经营现金流/净利润；应收周转天数同比
- 稳健型：正利润下近12个月经营现金流/净利<0.8，连续2期时提醒
- 平衡型：比值<0.5且应收周转天数同比+20%，连续2期时提醒
- 进取型：比值<0.3且应收周转天数同比+30%，连续2期时提醒
- 程度与影响：轻微(S1)现金转换弱；重要(S2)满足平衡组合；不是财务造假结论；盈利现金含量下降、营运资金占用、回款压力
- 合成例子：连续两次近12个月比值均0.4，应收天数由50至65天(+30%)→重要(S2)；金融业不套用。
- 不要误读：现金流弱不等于造假；金融行业、亏损公司和季节性业务需要其他口径。
- 当前实现：未接入；需要公告和财报

#### C03 近期债务还不还得上

把可用现金、近期到期债务和可靠融资来源放在一起看。

- 看什么数据：非受限现金、未来一年到期债务、授信、契约
- 怎么计算：现金/未来一年到期债务；还款与违约状态
- 稳健型：非受限现金/一年内到期债务<1时提醒
- 平衡型：比值<0.5且90天到期债务>可用现金时提醒；正式违约即时提醒
- 进取型：比值<0.3且30天到期债务>可用现金时提醒；正式违约即时提醒
- 程度与影响：轻微(S1)覆盖率<1；重要(S2)平衡组合命中；严重(S3)正式违约/确认违约条款触发；再融资压力、偿付风险、潜在债务重组
- 合成例子：可用现金4亿、一年到期债务10亿、90天到期5亿→覆盖0.4，重要(S2)；银行授信另核，不据此断言破产。
- 不要误读：现金不足是偿债压力，不等于已经违约；只有正式事实才能称违约。
- 当前实现：未接入；需要公告和财报

#### C04 财报是否还值得信赖

看审计意见或财报更正的具体内容，判断哪些时期、哪些数字受到影响。

- 看什么数据：审计意见、财务重述、旧财报可信赖状态
- 怎么计算：相对上期审计或原财报的正式变化
- 稳健型：保留意见或实质财务重述即提醒
- 平衡型：否定/无法表示意见，或关键旧财报不再可信赖时提醒
- 进取型：与平衡型相同；重大审计事实不因偏好过滤
- 程度与影响：轻微(S1)保留意见/待核重述；重要(S2)关键财报失去可信赖；严重(S3)否定/无法表示意见且涉及持续经营等核心问题；财报可信度和估值依据可能失效
- 合成例子：审计无法表示意见且指出核心持续经营不确定→严重(S3)；普通强调事项不等于造假。
- 不要误读：更换审计师或普通强调事项不自动证明财报不可信，更不能直接说造假。
- 当前实现：未接入；需要公告和财报

#### C05 调查、官司或处罚影响经营

分清调查、审理、裁决和处罚阶段，再看金额或许可变化是否影响主营业务。

- 看什么数据：调查、处罚、诉讼、许可状态、涉案主体
- 怎么计算：程序阶段与直接经营/金额影响
- 稳健型：正式调查/立案即提醒，并写明阶段
- 平衡型：处罚/裁决/许可限制对主营有确认的重要影响时提醒
- 进取型：一般调查入摘要；核心许可受限/重大裁决或严重(S3)即时提醒
- 程度与影响：轻微(S1)调查阶段；重要(S2)重要处罚/裁决；严重(S3)核心经营资格被撤销；合规成本、赔付、经营资格变化
- 合成例子：监管正式撤销主营业务许可证→严重(S3)，各偏好均提醒；调查立案不能写成已认定违法。
- 不要误读：立案不等于认定违法；涉及母公司或同行也不一定涉及这家上市公司。
- 当前实现：未接入；需要公告和财报

#### C06 股东或管理层有重要变化

区分减持计划与实际卖出，并跟踪质押处置、控制权和关键人员变化。

- 看什么数据：减持计划/执行、质押、解禁、管理层离任
- 怎么计算：计划与执行分开；股份比例明确分母
- 稳健型：90日拟减持≥总股本1%或关键人员离任时提醒
- 平衡型：90日实际减持≥总股本3%或正式质押违约处置时提醒
- 进取型：90日实际减持≥总股本5%时提醒；正式违约处置不延后
- 程度与影响：轻微(S1)计划/离任；重要(S2)实际减持≥3%；严重(S3)须另有控股权强制变更等重大确认事实；潜在供给压力、治理连续性或控制权风险
- 合成例子：90日已执行减持占总股本3.2%→重要(S2)；解禁3.2%但尚未卖出不能当实际减持。
- 不要误读：离职不等于内部人看空；解禁不等于减持；质押不等于已经被强制卖出。
- 当前实现：未接入；需要公告和财报

#### C07 增发或回购改变每股权益

看新增股份、融资价格、资金用途和回购执行，判断每股权益与融资条件如何变化。

- 看什么数据：增发、配售、供股、可转债、回购执行
- 怎么计算：新增普通股/发行前普通股；计划/完成/取消分别记录
- 稳健型：潜在摊薄≥5%或重要回购进度改变时提醒
- 平衡型：潜在摊薄≥10%或重要回购撤销时提醒
- 进取型：潜在摊薄≥20%时提醒；融资失败导致偿付问题走C03
- 程度与影响：轻微(S1)摊薄≥5%；重要(S2)≥10%或重要回购撤销；不自动定严重(S3)；每股指标摊薄、融资成本、现金管理预期变化
- 合成例子：发行前1亿股，拟新增1200万股→按发行前股本摊薄12%，重要(S2)；不是新增股占发行后股本。
- 不要误读：增发可能摊薄权益，但资金也进入公司；回购不保证股价上涨。
- 当前实现：人工整理融资事件；不是自动公告解析。当前事件未按三档语义做自动筛选。

#### C08 事故或停产影响正常生意

确认事故、召回、停产或重大订单取消的范围，跟踪经营是否恢复。

- 看什么数据：停产、事故、召回、关键订单取消、网络事件
- 怎么计算：已确认的业务范围、收入占比、停产时长
- 稳健型：确认事件涉及业务收入占比≥10%即提醒
- 平衡型：主营中断或受影响业务收入占比≥20%时提醒
- 进取型：占比≥30%时提醒；确认核心业务停摆各偏好即时提醒
- 程度与影响：轻微(S1)范围待查/占比≥10%；重要(S2)重要业务受限；严重(S3)核心主营完全停摆；产量、交付、收入或修复成本变化
- 合成例子：收入占比25%的工厂确认停产→重要(S2)；收入占比不是利润损失率；正式恢复更新原事件。
- 不要误读：受影响业务占收入25%不等于利润一定损失25%。
- 当前实现：人工整理经营事件；原文、范围尚未逐条核验。

#### C09 上市资格或交易状态改变

依据交易所公告，分清临时停牌、风险警示、退市程序和最终退市决定。

- 看什么数据：停复牌、风险警示、退市程序、上市阶段
- 怎么计算：交易所确认的新状态与生效时间
- 稳健型：官方预告状态变化入摘要；正式新增状态即时提醒
- 平衡型：正式停牌/风险警示/退市程序即时提醒
- 进取型：与平衡型相同；交易可行性事实不延后
- 程度与影响：轻微(S1)提前日程；重要(S2)临时停牌/风险警示；严重(S3)正式退市决定/长期无法交易；进入程序≠已退市；无法交易、流动性下降、上市资格风险
- 合成例子：交易所公告临时停牌→重要(S2)，三档均提醒；仅启动退市程序不能写成已退市。
- 不要误读：进入退市程序不等于已经退市；临时停牌不等于永远无法交易。
- 当前实现：未接入；需要公告和财报

### 数据核验

#### C10 先排除拆股、除权造成的假跌幅

在比较价格前，确认拆股、分红等公司行为，把前后价格放到可比较的口径。

- 看什么数据：分红除权、拆并股、配股参考价、ADR比例
- 怎么计算：原始价与已知公司行为调整后的可比价
- 稳健型：所有行情判断前强制校正；自身不推价格风险
- 平衡型：同左；校正后再判P01—P12
- 进取型：同左；不可关闭数据口径校正
- 程度与影响：校正门槛，不单独赋S等级；真实融资稀释另看C07；避免拆股、除权带来的机械跌幅误报
- 合成例子：1拆2，原价100变50、股数翻倍→经济价格变化0%，抑制50%暴跌误报。
- 不要误读：校正的是机械价格变化；校正后仍然存在的真实涨跌，继续按原规则检查。
- 当前实现：原始日线标为前复权；尚无独立公司行为核验流程，不能称完整实现。

#### Q01 消息是否有可靠出处

追溯原文、判断转载关系，区分正式事实、媒体报道、传闻和相互冲突的信息。

- 看什么数据：原始来源、转载链、确认状态、冲突证据
- 怎么计算：官方文件/公司披露/独立报道/匿名线索分层
- 稳健型：一律先分来源；传闻仅待核实，不生成已确认事实
- 平衡型：同左；风险偏好不放宽证据标准
- 进取型：同左；风险偏好不放宽证据标准
- 程度与影响：数据状态D：待核实/冲突；不以转载数量升为重要(S2)/严重(S3)；防止来源重复、传闻及注入指令造成错误归因
- 合成例子：10篇文章转载同一匿名帖→仍是1个源、待核实；文章要求忽略规则也不得执行。
- 不要误读：十篇转载可能只有一个来源；资料中的指令不具有用户授权。
- 当前实现：未接入；需要来源、时间和处理状态的核验流程

#### Q02 数据是否还有效

根据数据源承诺的更新频率，检查当前数据有没有过期或获取失败。

- 看什么数据：供应商更新时间、抓取时间、延迟契约、交易状态
- 怎么计算：当前时间−数据发布时间，按数据频率与开闭市判断
- 稳健型：按供应商延迟契约处理，不能按风险偏好放宽
- 平衡型：同左；过期/失败停算依赖项并提示服务状态
- 进取型：同左；不能把过期行情当最新
- 程度与影响：D降级/不可用；不是股票风险S等级；数据盲区，可能漏监控；应展示最近成功更新时间
- 合成例子：实时源契约60秒，缓存已35分钟且重试失败→D，停算价格规则；不输出股票安全。
- 不要误读：没有新成交不一定是断线；数据缺失不能写成没有风险。
- 当前实现：未接入；需要来源、时间和处理状态的核验流程

#### Q03 重复消息合并，新进展跟进

同一事实多次出现时只保留一件事；事实改变时更新原事件。

- 看什么数据：事件ID、事实版本、上次提醒、风险解除
- 怎么计算：同事实去重，实质更新另立版本
- 稳健型：同事实去重；价格冷却可选15分钟，重大更新立即覆盖
- 平衡型：同事实去重；价格冷却默认30分钟，重大更新立即覆盖
- 进取型：同事实去重；价格冷却可选60分钟，重大更新立即覆盖
- 程度与影响：执行状态：归并/更新；不改变原事件S等级；减少反复打扰，同时保留恶化、解除及更正
- 合成例子：同一政策被转载10次→只保留1次提醒意图；新增豁免条款更新原事件，不等冷却结束。
- 不要误读：不因改标题或换媒体重复提醒；澄清、恶化和解除仍需要更新。
- 当前实现：部分实现：按人工原因线及事件关联归并展示；尚无完整原文指纹、事实版本和分钟冷却核验流程。

#### Q04 数字是否在说同一件事

核对数字的单位、币种、期间和版本；口径一致后才比较。

- 看什么数据：单位、币种、期间、会计口径、数值版本
- 怎么计算：统一口径后按预设误差容限核对
- 稳健型：统一单位/期间/币种；冲突阻止受影响结论
- 平衡型：同左；不可放宽到自动平均冲突值
- 进取型：同左；不可放宽到用0替代缺失
- 程度与影响：D口径冲突/缺失；不等同S0正常；防止单位差、修订信息穿越与错误比率
- 合成例子：一个源成交量100万手、另一个1亿股；按该证券100股/手统一后相同，不是巨大冲突。
- 不要误读：缺失不是0；修订后的数据不能偷偷放进修订前的回放。
- 当前实现：未接入；需要来源、时间和处理状态的核验流程

### 用户规则

#### U01 这件事和我的仓位有多大关系

在用户提供持仓后，计算单股和主题集中度，帮助安排提醒顺序。

- 看什么数据：自选、授权持仓、行业/地区/币种暴露
- 怎么计算：同估值时间、同基础币种的持仓权重
- 稳健型：用户可选单股≥20%或同主题≥40%时提醒
- 平衡型：用户可选单股≥30%或同主题≥50%时提醒
- 进取型：用户可选单股≥40%或同主题≥60%时提醒
- 程度与影响：个性化超限，不作全市场S等级；关联事件等级独立保留；组合集中暴露；主题有交叉时先证券去重再求和
- 合成例子：授权仓位中单股32%，平衡配置30%→一次超限提醒；仅自选无持仓时不能计算。
- 不要误读：自选不等于持有；不知道仓位就不能计算个人损失或集中度。
- 当前实现：部分实现：仓位影响提醒优先级；完整主题集中度等目标规则未接入。

#### U02 按用户确认的关注条件提醒

保存用户明确指定的对象、指标、条件、有效期和通知开关，并在适用范围内执行。

- 看什么数据：投资逻辑、自定义条件、提醒偏好和有效记忆
- 怎么计算：结构化规则：对象/字段/运算符/阈值/周期/连续次数
- 稳健型：使用用户确认规则；可选提前一期给未达成观察提示
- 平衡型：严格达到字段/窗口/连续次数才提醒
- 进取型：仍执行用户确认规则，不擅自提高用户明确阈值
- 程度与影响：自定义命中；事件S等级另外记录；规则未满足不得标已触发；投资逻辑变化与个人关注偏好，不代表市场统一风险
- 合成例子：用户设连续2季毛利率<30%；两季29%、28%→命中。关闭MA提醒仅作用于指定证券。
- 不要误读：点过新闻不等于想增加提醒；模糊要求先澄清；过期或删除的规则不继续用。
- 当前实现：部分实现：按指标全局选档/关闭；不支持单证券规则范围与到期失效的完整目标语义。

## 政策要引入哪些内容

政策先过四关：**有没有正式原文 → 与旧规则有无实质变化 → 公司业务是否实际适用 → 能否解释重要影响**。草案先观察，尚未生效的正式政策可以提前提醒，撤销或豁免则更新原事件。

| 类别 | 引入内容 | 影响路径 |
|---|---|---|
| 货币与信用 | 加息/降息、降准、流动性工具、缩表/扩表、地产信贷约束 | 融资成本、估值折现、银行息差、负债偿付 |
| 财政、税收与补贴 | 企业税、消费税、出口退税、补贴资格/标准/到期 | 税后利润、现金补助、采购需求、合规成本 |
| 贸易与出口管制 | 关税、反倾销、出口许可、禁限清单、实体与最终用途限制 | 出口订单、进口成本、关键设备/原料获取 |
| 产业准入、许可与定价 | 行业许可证、产品审批、经营准入、药品/公用事业限价 | 是否能继续经营、市场准入、产品毛利 |
| 需求与政府采购 | 消费补贴、以旧换新、住房需求政策、基建预算、政府采购 | 销量、订单来源、回款、需求持续性 |
| 供给、能源与环保 | 能耗约束、排放标准、产能许可、限产、资源与电价安排 | 产量、资本开支、能源成本、供应中断 |
| 数据、平台与竞争监管 | 数据跨境、隐私、安全审核、算法/平台经营规则、反垄断 | 数据可用性、业务合规、获客/运营成本、经营资格 |
| 资本市场与跨境资金 | 上市/退市、交易机制、再融资、互联互通资格、资本流动安排 | 流动性、融资可得性、上市地资格、可交易范围 |

每条政策保留签发机构、原文/文号、发布时间、系统可得时间、生效时间、状态、适用主体/产品/地区、新旧差别和豁免。公司关联使用公告或业务披露证明，不能只靠模型猜。

## 三个市场怎么分别使用

|---|---|---|
| A股 | 先识别交易所、板块、上市阶段及当日有效规则；成交量“手/股”和流通股本统一后才算换手。限价与暂停只采信适用规则及交易所状态，不能一律按10%。 | 政策适用的行业、产品和地区；股东减持计划与执行；限价下未成交的流动性压力。 |
| 港股 | 先确认每手股数、港元/其他币种及报价时点；把“最后成交很久以前”与“数据连接过期”分开。A/H比较必须对齐币种、股份单位和可比时点。 | 稀疏成交、价差与可成交深度；配售融资、控制权与停牌公告；内地业务的真实政策关联。 |
| 美股 | 按当地交易日与时区对齐数据；常规、盘前、盘后各用可比基线。先校正拆股等公司行为；暂停状态依据交易所信息。 | 财报与指引、盘后事件、监管披露；客户或供应商变化先核实关系，不能只看美股龙头涨跌。 |

## 名词用人话解释

| 名词 | 解释 |
|---|---|
| 量比 / 成交量倍数 | 成交股数是可比基准的几倍。盘中比同一时点的累计股数，日终比完整交易日；大于1只是高于基准。 |
| 换手率 | 成交股数÷当时有效流通股数。是股份被交易的频繁程度，不是卖出股东比例。 |
| 均线 / 成交均价 | 均线是若干天收盘价的平均；成交均价按成交股数加权。两者都不是所有持有者的成本。 |
| 异常分数z / MAD | 超预期差=公布值−事先保存的预期。z=(本次差−历史差中位数)/(1.4826×历史绝对偏差中位数MAD)。此前24次同口径、MAD>0才计算。 |
| 历史分位 | 95分位意味着比历史约95%的同口径观测更高；不是未来下跌概率95%。 |
| ATR14 | 以14期真实波幅衡量平时价格起伏。真实波幅取“当日高低差、高价与前收差绝对值、低价与前收差绝对值”中最大值，再按固定方法平滑。 |
| S0 / S1 / S2 / S3 | S0只表示本题被检查的规则未触发；S1留意，S2重要，S3严重。数据缺失用“未知”，不能填S0。正向异动也不等于利空。 |
| 提醒次数 | 评测中的次数是沙箱记录的提醒意图；真实外发始终0。通知开关影响是否发送，不修改已确认的事实程度。 |
