# 异动管家 · 自选异动监测 AI 管家

针对「行情与资讯信息繁杂，想提前洞悉自选标的风险」的诉求做的产品原型：监测自选股上的宏观政策与微观指标异动，给出可验证的判断，到期按真实行情结算。

纯前端，没有后端。手机和 PC 共用一套页面。

## 现在能演示什么

在线演示：https://jackychen-12.github.io/anomaly-butler/

- **今日**：管家先开口。每件事一张卡，固定说四点：发生了什么、为什么和你有关、管家怎么看、你可以做什么。顶部是管家根据记住的事给出的主动提示，底部可以直接提问。
- **自选**：A 股、港股、美股共 8 只自选，异动标在命中的那一行；点开看走势、原因、证据和管家的判断。
- **复盘**：每条判断事先写明「跌破哪个价算说对」，到期按真实收盘价对答案。说对、说错、作废都保留，并写下为什么、漏看了什么、以后怎么改；还能看到哪类信号准、哪类不准。
- **信号库**：异动监测信息集。每类信号 = 内容（看什么、数据来源、触发规则）+ 评测（历史回测或案例内判断结果）。可导出为 Markdown，见 `docs/异动监测信息集.md`。
- **我的**：持仓可选补充（手动填或模拟券商导入），补充后提醒按仓位排序，并给出事前、事后的调仓做法；「管家记得的事」列出它记下的表态、偏好、调仓选择和提问，可逐条删除；设置里可接入自己的模型接口。
- **案例回放**：2025 年 4 月关税冲击。点「下一天」，只能看到那一刻之前的行情和事件。

## 数据说明

| 内容 | 来源 |
|---|---|
| 日线行情 | 真实数据，东方财富（经 akshare），前复权，`src/data/prices.json` |
| 价量异动 | 由日线按规则计算（单日涨跌幅绝对值达到 7%） |
| 宏观与公司事件 | 人工整理的真实事件，`src/data/case.ts`，文字与来源尚未逐条核对 |
| 判断结算 | 由真实收盘价自动计算，没有人工指定结果 |
| 复盘文字 | 人工撰写，`src/data/case.ts`；只在与实际结算结果一致时展示 |
| 信号评测 | 规则类由日线回测计算；事件类统计案例内判断 |
| 示例持仓、预置表态 | 模拟数据 |

重新拉取行情：`python scripts/fetch_prices.py`（需要 akshare）。重新导出信号集文档：`npx tsx scripts/export-signals.ts`。
