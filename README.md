# 异动管家 · 自选异动监测 AI 管家

针对「行情与资讯信息繁杂，想提前洞悉自选标的风险」的诉求做的产品原型：监测自选股上的宏观政策与微观指标异动，给出可验证的判断，到期按真实行情结算。

纯前端，没有后端。手机和 PC 共用一套页面。

## 现在能演示什么

在线演示：https://jackychen-12.github.io/anomaly-butler/

PC 上是左右分栏：最左是导航栏，中间和右边按页面分成「列表 + 详情」或「主内容 + 侧栏」；手机上收成一列，列表点开看详情，底部是标签栏。

- **今日**：先用两张图看全局：每只自选股的涨跌、按板块汇总的涨跌（填了持仓会加上仓位和对总资产的影响），有新异动的打圆点。下面每件事一张卡，只留标题、受影响的股票、管家的判断和「离跌破线还有多远」的进度条，文字细节点开再看。右边是提问栏（手机上是底部输入条）。
- **自选**：左边是 A 股、港股、美股共 8 只自选，异动标在命中的那一行；右边是选中股票的走势、原因、证据和管家的判断。
- **复盘**：左边是全部判断，右边是和管家就一条判断的对话。结果出来前在对话里表态、说理由；出来后管家讲为什么对或错、漏看了什么，并提出一条经验，你决定记不记，也可以写下自己的经验。
- **长期记忆**：记下的经验按信号归类。以后同类信号的判断再出现，管家会把对应的经验拿出来参考，并在判断旁边写明。
- **信号库**：异动监测信息集。左边是 14 类信号，右边是选中信号的内容（看什么、数据来源、触发规则）、评测（历史回测或已发出判断的结果）和积累的经验。可导出 Markdown，见 `docs/异动监测信息集.md`。
- **我的**：投资画像（能接受的最大跌幅、持有周期、遇到大跌的习惯、自己的原则），管家据此调整提醒等级、在判断旁对照说明、在调仓时标出更接近你风格的做法并在你偏离时提醒；持仓可选补充（手动填或模拟券商导入），左边填持仓、右边看事前和事后的调仓做法；长期记忆。

演示固定展示 2025 年 4 月 9 日早上开盘前的状态，只使用这一刻之前的行情和事件。汇报时要换一天验证，可在网址后加 `?date=2025-04-03` 这样的参数（须是演示数据里的交易日）。

## 数据说明

| 内容 | 来源 |
|---|---|
| 日线行情 | 真实数据，东方财富（经 akshare），前复权，`src/data/prices.json` |
| 价量异动 | 由日线按规则计算（单日涨跌幅绝对值达到 7%） |
| 宏观与公司事件 | 人工整理的真实事件，`src/data/case.ts`，文字与来源尚未逐条核对 |
| 判断结算 | 由真实收盘价自动计算，没有人工指定结果 |
| 复盘文字 | 人工撰写，`src/data/case.ts`；只在与实际结算结果一致时展示 |
| 预置经验 | 三条较早判断的经验预置在长期记忆里，界面上标了「演示预置」 |
| 信号评测 | 规则类由日线回测计算；事件类统计已发出的判断。都只用「今天」之前的数据 |
| 示例持仓、预置表态 | 模拟数据 |

重新拉取行情：`python scripts/fetch_prices.py`（需要 akshare）。重新导出信号集文档：`npx tsx scripts/export-signals.ts`。

## 开发

```bash
npm run dev
```

```bash
npm run build
```

技术栈：Vite、React、TypeScript、Tailwind CSS。设计语言沿用 WealthPilot（Notion 风格）。

## 尚未完成

- 事件与复盘文字的日期、数字和来源尚未逐条核对
- 复盘对话里管家的话由规则和预先写好的复盘文字生成；提问由内置规则回答，能答的问题有限。调用模型接口的代码保留在 `src/assistant.ts`，界面上暂不提供配置入口
- 经验目前只是被拿出来展示和参考，还不会自动改变信号的强度或判断的阈值
- 板块涨跌按自选股的简单平均计算，不是市场上的板块指数
- 资金、财报、解禁等信号在信号库中标为「规划中」，没有接入数据
- 评测样本很小，且所在时期市场大跌，数字只能参考

页面排版参考了 [daily_stock_analysis](https://github.com/ZhuLinsen/daily_stock_analysis) 的 Web 界面（左侧导航、列表加详情的分栏方式），未使用其代码。

本项目为演示用途，不构成投资建议。
