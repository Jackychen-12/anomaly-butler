# 异动管家 · 自选异动监测 AI 管家

针对「行情与资讯信息繁杂，想提前洞悉自选标的风险」的诉求做的产品原型：监测自选股上的宏观政策与微观指标异动，给出可验证的判断，到期按真实行情结算。

纯前端，没有后端。手机和 PC 共用一套页面。

## 现在能演示什么

在线演示：https://jackychen-12.github.io/anomaly-butler/

这是一个金融场景下的个人助理：帮你盯自选股的异动，把每件事按固定的顺序想清楚，到期对答案，并把经验、你的习惯和偏好记进长期记忆，之后主动拿出来用。

PC 上是左右分栏：最左是导航栏，中间和右边按页面分成「列表 + 详情」或「主内容 + 侧栏」；手机上收成一列，列表点开看详情，底部是标签栏。

- **今日**：从上到下是：
  - **两张图**：每只自选股的涨跌、按板块汇总的涨跌（填了持仓会加上仓位和对总资产的影响）。
  - **宏观**：政策与跨市场的事，涨的和跌的都算。今天新出现的画出传导路径（事件 → 通过什么途径 → 影响到哪几只自选股）；近几天出现、还在起作用的收成一行，点开再看。美股龙头隔夜大涨大跌会自动映射到相关的 A 股、港股。
  - **微观**：公司自己的事，和行情指标的异动（大涨大跌、量比放大、跌破或站上均线、连续涨跌、阶段新高新低），一只股票一行；影响轻微的默认收起。
  - **提前看**：管家认为未来几天会明显涨或跌的自选股，每只一条进度条，显示离「到了就算说对」的价格还有多远。
  - **右侧对话栏**（手机上是底部输入条）：管家先开口（问候加主动提醒），下面是可以直接点的问题；回答里带股票标签、战绩条和去处。
- **自选**：按今天的重要程度分成重要、留意、轻微、平静四组；右边是选中股票的走势、异动和管家的判断。
- **判断**：每条判断按同样的五步走：发生了什么（传导路径）→ 管家怎么看（走势、离跌破线多远、依据）→ 你怎么看（同意或不同意落在哪一环：事件本身、传导路径、价格是否已反映、后面会不会缓和）→ 你打算怎么做（持有时给出几种做法和代价）→ 对答案与复盘（预测与实际的对比图、谁对了、原因、一张由你决定记不记的经验卡）。
- **信号库**：管家靠什么判断「这是异动」。按宏观、微观列出 21 类信号；行情指标的阈值可以自己调（比如量比到多少才算放量），评测跟着重算，每个信号都可以关掉。管家会试别的阈值，发现历史上更准的就提出建议，由你决定改不改。可导出 Markdown，见 `docs/异动监测信息集.md`。
- **我的**：
  - **管家设置**：它能做什么（盯异动、画传导路径、给判断、复盘、自己试更准的阈值、列调仓做法）、用的什么模型、记得什么、什么时候主动找你、连着哪些数据和账户。记忆、主动提醒和自动试阈值都有开关。
  - **投资画像**：能接受的最大跌幅、持有周期、遇到大跌的习惯、单只仓位上限、自己的原则。管家据此调整提醒等级、在判断旁对照说明、在调仓时标出更接近你风格的做法并在你偏离时提醒。
  - **持仓**：可选补充（手动填或模拟券商导入）。
  - **长期记忆**：关于你（设定的画像 + 管家从表态和调仓选择里观察到的你）、经验（按信号归类）、我的逻辑（每种理由用过几次、看对几次）、管家记下的事。

演示固定展示 2025 年 4 月 9 日早上开盘前的状态，只使用这一刻之前的行情和事件。汇报时要换一天验证，可在网址后加 `?date=2025-04-03` 这样的参数（须是演示数据里的交易日）。

## 数据说明

| 内容 | 来源 |
|---|---|
| 日线行情 | 真实数据，东方财富（经 akshare），前复权，`src/data/prices.json` |
| 行情指标异动 | 由日线按规则计算：大涨大跌、量比、跌破或站上均线、连续涨跌、阶段新高新低；阈值可在信号库里调 |
| 跨市场映射 | 由美股日线按规则计算，映射关系人工指定（目前只有苹果 → 立讯精密、小米），`src/data/case.ts` 的 `CROSS` |
| 传导路径 | 人工整理，`src/data/case.ts` 的 `paths` |
| 宏观与公司事件 | 人工整理的真实事件，`src/data/case.ts`，文字与来源尚未逐条核对 |
| 判断结算 | 由真实收盘价自动计算，没有人工指定结果 |
| 复盘文字 | 人工撰写，`src/data/case.ts`；只在与实际结算结果一致时展示 |
| 预置经验 | 三条较早判断的经验预置在长期记忆里，界面上标了「演示预置」 |
| 信号评测 | 规则类由日线回测计算；事件类统计已发出的判断。都只用「今天」之前的数据 |
| 示例持仓、预置表态 | 模拟数据 |

重新拉取行情：`python scripts/fetch_prices.py`（需要 akshare）。重新导出信号集文档：`npx tsx scripts/export-signals.ts`。

## 尚未完成

- 事件与复盘文字的日期、数字和来源尚未逐条核对
- 复盘对话里管家的话由规则和预先写好的复盘文字生成；提问由内置规则回答，能答的问题有限。调用模型接口的代码保留在 `src/assistant.ts`，界面上暂不提供配置入口
- 管家会对行情指标的阈值提出调整建议；复盘得到的文字经验目前只是被拿出来展示和参考，还不会自动改变规则
- 板块涨跌按自选股的简单平均计算，不是市场上的板块指数
- 资金、财报、解禁等信号在信号库中标为「规划中」，没有接入数据；管家设置里的大模型、资讯与公告、盘前推送、微信和飞书同样标为「规划中」
- 换手率数据这次没有取到（行情接口不稳定），「换手率异常」信号已写好但暂时不会触发；重新运行 `scripts/fetch_prices.py` 取到后即可生效
- 评测样本很小，且所在时期市场大跌，数字只能参考
