# 异动管家 · 自选异动监测 AI 管家

针对「行情与资讯信息繁杂，想提前洞悉自选标的风险」的诉求做的产品原型：监测自选股上的宏观政策与微观指标异动，给出可验证的判断，到期按真实行情结算。

纯前端，没有后端。手机和 PC 共用一套页面。

## 现在能演示什么

- **自选**：A 股、港股、美股共 8 只自选，异动直接标在命中的那一行；点开看走势、传导链、证据和管家判断。
- **分级**：等级 = 信号强度 × 持仓权重 × 你的偏好。未授权时持仓权重不参与；偏好可以就地改成「盯紧 / 默认 / 少提醒」。
- **判断与验证**：每条判断写明触发线和失效条件，你可以表态「认同 / 不认同 / 再观察」，到期和管家一起结算，命中、未中、作废都保留。
- **调仓**：模拟授权证券账户后，针对持仓股上待验证的判断给出三个方案，也可以自己拖动仓位，实时看到风险暴露的变化。只做记录，不下单。
- **时间机器**：案例是 2025 年 4 月关税冲击。把时间拨到任意一天的盘前，只能看到那一刻之前的行情和事件。

## 数据说明

| 内容 | 来源 |
|---|---|
| 日线行情 | 真实数据，东方财富（经 akshare），前复权，`src/data/prices.json` |
| 价量异动 | 由日线按规则计算（单日涨跌幅绝对值达到 7%） |
| 宏观与公司事件 | 人工整理的真实事件，`src/data/case.ts`，文字与来源尚未逐条核对 |
| 判断结算 | 由真实收盘价自动计算，没有人工指定结果 |
| 持仓、示例表态 | 模拟数据 |

重新拉取行情：`python scripts/fetch_prices.py`（需要 akshare）。
