# 异动管家 · 自选异动监测 AI 管家

针对「行情与资讯信息繁杂，想提前洞悉自选标的风险」的诉求做的产品原型：监测自选股上的宏观政策与微观指标异动，给出可验证的判断，到期按真实行情结算。

纯前端，没有后端。手机和 PC 共用一套页面。

## 现在能演示什么

在线演示：https://jackychen-12.github.io/anomaly-butler/

这是一个金融场景下的个人助理：帮你盯自选股的异动，把每件事按固定的顺序想清楚，到期对答案，并把经验、你的习惯和偏好记进长期记忆，之后主动拿出来用。

PC 上是左右分栏：最左是导航栏，中间和右边按页面分成「列表 + 详情」或「主内容 + 侧栏」；手机上收成一列，列表点开看详情，底部是标签栏。

- **今日**：先说今天有几件事要看，再分宏观、微观列出来。
  - **归并**：管家把一条条信号按原因并成「事」。同一条线上的事件（比如关税的几次升级）算一件，只展开最新的，前面的列成「之前的进展」；行情指标和跨市场的异动能对上原因的，挂在那件事下面，不再各算一条。标题、导航角标、对话栏开场白用的是同一个数。
  - **漏斗**：标题下面一条细的漏斗——捕捉到几条信号、归并成几件事、几件要看。
  - **打扰预算**：每天最多 3 件事可以标成「高」（可在管家设置里改成 1 或 5），其余降到「中」。
  - **两张图**：自选变化、板块变化，有持仓时带仓位。
  - **接下来要留意的日子**：已公布政策的生效日和各条判断的对答案日，画成一条时间线。
  - **最近有结果**：按事件归在一起，一件事一行。
  - **右侧对话栏**（手机上是底部输入条）：管家先开口（问候加主动提醒），下面是可以直接点的问题。某项指标的判断连着说错时，管家会提议把它的门槛调高一档，点一下生效。
- **自选**（按股票看：发生了什么，我的仓位怎么办）：按今天的重要程度分成重要、留意、轻微、平静四组；右边是选中股票的走势和异动（新出现的在最上面，之前的按日期分组，可按宏观、微观筛选）。右栏三块：这条异动有多重要、管家对它的判断（点开去判断页）、我的仓位现在怎么办——持有这只股票且管家有判断时，在这里从三种做法里选一种记下来，只记录不下单。
- **判断**（按判断看：管家说得准不准，我看得对不对）：每条判断按同样的四步走：发生了什么（传导路径）→ 管家怎么看（走势、离跌破线多远、依据）→ 你怎么看（同意或不同意落在哪一环：事件本身、传导路径、价格是否已反映、后面会不会缓和）→ 对答案与复盘（预测与实际的对比图、谁对了、原因、一张由你决定记不记的经验卡）。仓位不在这里定；对答案时会回头看你在自选里记下的做法，和不动相比总资产多了还是少了。
- **信号库**：管家靠什么判断「这是异动」。按《异动监测指标设计与分级规则》列出 38 项指标（宏观 6、行业 4、量价 12、公司基本面 10、质量门槛 4、用户 2），分宏观、微观、门槛与个人三段。每项都有稳健、平衡、进取三档提醒门槛：先选一个默认档位（设好投资画像后会给出建议），再对单项指标单独切换或关掉；异动等级 S1–S3 不随档位变。已接入的 9 项（P02 量比、P05 回撤、P06 均线、P10 量价组合、P11 跳空、I03 跨市场传导、M03 政策、C07 融资、C08 重大事件）有回测评测，其余全部列出并标明缺什么数据。材料审核版见 `docs/异动监测信息集.md` 与 `docs/异动监测信息集与评测事件.xlsx`：保留原五张表，用六类说明38项指标，区分目标规则与当前实现，并新增36个Agent行为评测题（尚未运行）。完整输入、参考Trace和判分断言见 `docs/Agent评测事件.jsonl`，执行方法见 `docs/Agent评测设计.md`。原60条异动和12条历史预测保留；历史预测不作为Agent评测成绩。旧 `scripts/export-dataset.ts`、`scripts/build_dataset_xlsx.py` 和 `scripts/export-signals.ts` 仍导出原型快照，重导请另存，不覆盖审核版；原指标导入脚本也未适配新版审核表。
- **我的**：五页各管一件事。
  - **投资画像**：你告诉管家的。上面是概览（风险偏好、持有周期、持仓集中度三条轴，同时标出「你说的」和「管家观察到的」，对不上时提醒）；下面是七项设定加自己的原则，每项写明用在哪个功能上。
  - **持仓**：演示里默认已从模拟券商导入一份持仓，可以手动改或清空。
  - **长期记忆**：管家记住了关于你的什么。最上面是「管家眼中的你」一段话；下面是一条条记住的事，分关于你、经验、你写的三类，每条写明用在哪、从哪来，可以自己加、可以删；还没记住的列在后面；原始的操作记录收在最下面。
  - **管家设置**：它能做什么、什么时候主动找你（含打扰预算和开盘前推送的预览）、大模型、通用开关。大模型一栏填上 key 并测试通过后，问答、每天的开场白和「管家眼中的你」由模型根据管家掌握的资料来写；没填时由内置规则生成。key 只存在浏览器里，不进仓库。
  - **订阅**：参考 Claude 的订阅制，各档能用的功能基本一样，差的是模型用量。免费版、Pro（免费版的 5 倍）、Max（Pro 的 5 倍或 20 倍）；用量按模型消耗的 token 计，每 5 小时一个时段，付费档另有每周上限，用完可以等重置、换大一档或开额外用量。内置规则完成的事（行情指标异动、对答案等）不占用量。是演示：没有真的调用大模型，用量按在演示里做过的事折算；不扣费，其他页面的功能暂不受限；价格和额度是示意。

画像各项和功能的对应：

| 画像里的一项 | 用在哪 |
|---|---|
| 能接受的最大跌幅 | 每条看跌判断旁的对照说明；调仓时的提示 |
| 一般拿多久 | 异动等级：长线少提醒短期的行情波动，短线多提醒 |
| 遇到大跌通常怎么做 | 判断第四步标出更接近你的做法；选得不一样时提醒 |
| 单只仓位上限 | 持仓超限时主动提醒 |
| 这笔钱的目标 | 和前两项一起决定风险类型 |
| 主要看什么 | 异动等级：看重的那几类上调，其余略下调 |
| 投资经验 | 新手会在指标旁多看到一句名词解释 |
| 我的原则 | 判断第四步做选择时摆在旁边对照 |

演示固定展示 2025 年 4 月 9 日早上开盘前的状态，只使用这一刻之前的行情和事件。汇报时要换一天验证，可在网址后加 `?date=2025-04-03` 这样的参数（须是演示数据里的交易日）。

## 数据说明

| 内容 | 来源 |
|---|---|
| 日线行情 | 真实数据，东方财富（经 akshare），前复权，`src/data/prices.json` |
| 行情指标异动 | 由日线按规则计算：量价组合（日收益 × RVOL20）、日终成交量倍数、20 日回撤、跌破 MA20、开盘跳空 ÷ ATR14；门槛按信号库里选的档位 |
| 跨市场映射 | 由美股日线按规则计算，映射关系人工指定（目前只有苹果 → 立讯精密、小米），`src/data/case.ts` 的 `CROSS` |
| 传导路径 | 人工整理，`src/data/case.ts` 的 `paths` |
| 宏观与公司事件 | 人工整理的真实事件，`src/data/case.ts`，文字与来源尚未逐条核对 |
| 判断结算 | 由真实收盘价自动计算，没有人工指定结果 |
| 复盘文字 | 人工撰写，`src/data/case.ts`；只在与实际结算结果一致时展示 |
| 预置经验 | 三条较早判断的经验预置在长期记忆里，界面上标了「演示预置」 |
| 信号评测 | 规则类由日线回测计算；事件类统计已发出的判断。都只用「今天」之前的数据 |
| 示例持仓、预置表态 | 模拟数据 |

重新拉取行情：`python scripts/fetch_prices.py`（需要 akshare）。重新导出信号集文档：`npx tsx scripts/export-signals.ts`。

## 尚未完成

- 事件与复盘文字的日期、数字和来源尚未逐条核对
- 复盘对话里管家的话由规则和预先写好的复盘文字生成；提问由内置规则回答，能答的问题有限。在管家设置里接上大模型后，提问由模型根据同一份资料回答；事件、传导路径和复盘文字仍是预先写好的
